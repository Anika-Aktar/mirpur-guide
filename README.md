# Mirpur Guide 🏙️

A simple hometown homepage dedicated to **Mirpur, Dhaka, Bangladesh**, showcasing its local attractions and unique charm.

## ✨ Features
- Hometown introduction
- Local attractions and highlights
- Images and attractive styling

## 🛠️ Built With
- HTML5
- CSS3

## 🌐 Live Website
[anika-mirpur-guide.netlify.app](https://anika-mirpur-guide.netlify.app/)

## 🚀 Run Locally
Clone the repository and open `index.html` in your browser.

```bash
git clone https://github.com/Anika-Aktar/mirpur-guide.git
```
